# EUN V3 implementation plan

**Goal:** Redesign original EUN without changing its scientific calculations or JSON format; require login; remove all AWS dependencies and use free services.

**Architecture:** Static React/TypeScript application with the original classic Web Worker. Firebase Authentication Spark provides email/password accounts, verification and password reset. Cloudflare Pages hosts the static build. No uploaded sequencing data or cloud analysis compute. Local development uses Firebase's official Authentication emulator, never enabled in production.

**Design:** A calm lab notebook: warm white canvas, forest/teal actions, navy type, persistent tool navigation, sequential analysis setup, legible monospaced sequences, dense reports. V2 is context only, not the design template. No invented data or activity.

## Source audit
- Original: Uzihoon/eun @ 19072d41fcf4ff63411783208fca67b03b37751b.
- V2 reference: Uzihoon/eun-v2 @ f0cfeac8f0533ea09cf3dae720e86004963741e5.
- Original login uses Cognito and a guest bypass; config.js is not tracked. Replace both.
- Original public/worker.js joins reads, finds indicators, aligns with Needleman-Wunsch, counts substitutions/indels; retain byte-for-byte with pako.js and upstream attribution.
- Form supports SpCas9 NGG only, paired files, regex filename/index patterns, reference, guide, range (default 70), target/change nucleotide. Preserve engine constants filt_n=1, filt_r=5.
- Reports: reference highlights, five read metrics, aligned sequences/type/HDR, base frequencies, desired substitution rate; JSON and multi-sheet Excel.
- INDEL averages percentages equally across samples per uploaded report, cleavage marker, sequence list, zoom and PNG.
- Conversion: reverse alignment sequences, complement bases, merge reports; ordered transforms and ZIP output. Preserve legacy JSON semantics including unchanged format/summary metadata.
- Analysis List was a placeholder; show only actual current-session reports, with explicit temporary storage notice.

## Implementation and verification
1. Scaffold Vite, provenance manifest, local auth emulator and deployment guide.
2. Tests first for filename pairing, malformed JSON, unchanged engine hashes and conversion/INDEL parity against original source fixtures.
3. Implement typed engine adapter with bounded worker concurrency, progress, cancellation, surfaced errors and cleanup.
4. Implement Firebase auth, protected route gate, signup verification/reset, session validation and logout cleanup. Production must fail closed when unconfigured.
5. Implement analysis form, report, INDEL/chart and conversions, help and session list.
6. Run unit tests, TypeScript and production build. Browser tests cover actual emulator signup/login/logout, deep links, original sample analysis, import/export round trip, Excel/ZIP/PNG downloads and mobile overflow.
7. Record actual results and remaining deployment configuration. Do not create paid resources or publish without configured free accounts.
